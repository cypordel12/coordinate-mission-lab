THE CHALLENGE

When agents move at different speeds, altitudes and mission loads, a fixed rendezvous plan can quickly become outdated. COORDINATE explores how a decision support system can compare alternatives and make coordination trade-offs visible.

02 DECISION FRAMEWORK

Three ways to
coordinate.

The platform is designed to compare a fixed baseline, a simple heuristic and the proposed dynamic method under shared scenario conditions.
01 BASELINE

Static method

A predefined meeting plan used as a reference point for evaluating more adaptive approaches.

Fixed reference↗
02 RULE-BASED

Dynamic heuristic

A lightweight rule-based approach that selects an option using a limited set of operational indicators.

Fast comparison↗
